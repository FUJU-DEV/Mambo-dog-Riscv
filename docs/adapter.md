# 转接板设计说明（LQFP48 → LQFP64）

## 背景

原板主控为 **STM32F103C8T6**（ARM Cortex-M3，72MHz，64KB Flash / 20KB RAM，LQFP48），
新主控为 **CH32V307RCT6**（RISC-V 青稞 V4F，144MHz，256KB Flash / 64KB RAM，LQFP64）。
两种封装焊盘不兼容，因此设计一块小尺寸转接板，在不改动原 PCB 的前提下完成主控替换。

## 方案

| 项目 | 说明 |
|---|---|
| 板尺寸 | 13 × 13 mm 双面板 |
| 底面 | LQFP48 焊盘（镜像布局），焊回原板主控位置 |
| 顶面 | CH32V307RCT6 + 0.1µF 去耦电容 |
| 走线原则 | **全部引脚同名互连**（PA6↔PA6、PB8↔PB8 ……） |
| 焊接要点 | 转接板**翻面焊接**，转接板引脚 1 对准原板引脚 1 |

## CH32V307 独有引脚处理

| 引脚 | 处理 |
|---|---|
| VDD_4（19 脚） | 接 3.3V |
| VSS_4（18 脚） | 接 GND |
| PC0 ~ PC12、PD2 | 悬空 |

> 注意：VDD_4 / VSS_4 若不接电源，芯片无法正常工作；其余未用引脚悬空即可。

## 关键器件 LCSC 编号

| 器件 | 封装 | LCSC 编号 |
|---|---|---|
| STM32F103C8T6（原板主控） | LQFP48 | C8734 |
| CH32V307RCT6（新主控） | LQFP64 | C2988083 |
| 100nF 去耦电容 | 0402/0603 | C14663 |

## 引脚对应关系

全部外设引脚同名对应，完整映射见 [pin-mapping.md](pin-mapping.md)。
