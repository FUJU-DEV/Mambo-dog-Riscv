# ASRPRO 语音模块配置指南（A2 修复）

曼波小狗的语音控制依赖 **天问 ASRPRO 离线语音模块**：模块出厂是空白的，必须先用
[天问Block](https://www.tianwenblock.com/) 配置「识别词条 → 串口输出字符」并烧录。

## 1. 硬件连接

| ASRPRO 模块 | 接到 CH32V303CBT6 | 说明 |
|---|---|---|
| 5V | 5V 轨 | 模块供电 |
| GND | GND | 必须共地 |
| TX | PB11（第 22 脚，USART3_RX） | 模块发 → 主控收 |
| RX | PB10（第 21 脚，USART3_TX） | 主控发 → 模块（可选） |

串口参数：**9600 bps，8 数据位，1 停止位，无校验**。

## 2. 词条对照表（天问Block 里按此配置）

每个词条识别成功后，通过串口**输出单个 ASCII 字符**（固件按单字符协议分发）：

| 语音词条（示例，可换说法） | 输出字符 | 动作 |
|---|---|---|
| 前进 / 往前走 | `f` | 前进 |
| 后退 | `b` | 后退 |
| 左转 | `l` | 左转 |
| 右转 | `r` | 右转 |
| 前后摇 | `w` | 前后摇 |
| 左右摇 | `z` | 左右摇 |
| 跳舞 | `d` | 跳舞 |
| 立正 | `5` | 立正 |
| 起身 | `q` | 起身 |
| 坐下擦脸 | `s` | 坐下擦脸 |
| 交替抬手 | `j` | 交替抬手 |
| 伸懒腰 | `y` | 伸懒腰 |
| 抬头 | `1` | 抬头 |
| 趴下睡觉 | `p` | 趴下睡觉 |
| 卧下睡觉 | `2` | 卧下睡觉 |
| 打招呼 | `o` | 打招呼 |
| 难受 | `n` | 难受 |
| 表白 | `B` | 表白 |
| 元素周期表 | `Y` | 元素周期表 |
| 校训 | `X` | 校训 |
| 世界之光 | `W` | 世界之光 |
| 唤醒我 / 你好小狗 | `U` | 语音唤醒 |
| 你开心吗 | `K` | 查开心值 |
| 你累不累 | `T` | 查体力值 |
| 状态怎么样 | `Z` | 查开心+体力 |

> 注意：**字符区分大小写**（B/Y/X/W/U/K/T/Z 是大写，其余小写）。
> 固件对未知字符直接忽略（`default: break`），所以多输出换行符 \r\n 无害。

## 3. 天问Block 配置步骤

1. 打开天问Block → 新建工程 → 芯片选 **ASRPRO**（Core 板）；
2. 拖入「语音识别」模块，逐个添加词条（上表"语音词条"列）；
3. 每个词条的回调里加「串口输出」：`串口1.打印(字符)`（或等价积木），输出上表"输出字符"列；
4. 串口设置：**9600 / 8N1**；
5. 编译 → 用模块自带的 USB 口烧录；
6. 上电后对着模块说话，主控应能收到对应字符（可用串口助手在 PB10/PB11 侧验证）。

## 4. 验证方法

1. 主控烧好固件、ASRPRO 烧好词条；
2. 说"前进" → 舵机应执行前进步态，OLED 切换表情；
3. 说"跳舞" → 跳舞动作；
4. 若动作不对/无反应：先确认 ASRPRO 输出的字符（接 USB-TTL 到 PB10/PB11 抓包），
   再核对上表字符是否一致（尤其大小写）。

## 5. 替代方案

没有天问Block 或 ASRPRO 模块时，可直接用 **USB-TTL 串口模块**接 PB10/PB11（9600 8N1），
用串口助手手动发送上表字符，即可完整测试所有动作逻辑（无需语音模块）。
