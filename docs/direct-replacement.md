# 同脚位直插替换流程（STM32F103C8T6 → CH32V303CBT6）

## 背景

| 项目 | 原 STM32F103C8T6 | 新 CH32V303CBT6 |
|---|---|---|
| 内核 | ARM Cortex-M3 | 青稞 RISC-V V4F |
| 主频 / 存储 | 72MHz / 64KB + 20KB | 144MHz / 128KB + 32KB |
| 封装 | LQFP-48 (7×7) | LQFP-48 (7×7) |
| 引脚编号 | — | **与 F103C8T6 完全一致** |
| LCSC | C8734 | C7494374 |

两片芯片同为 LQFP-48、引脚编号逐一对应（见 [pin-mapping.md](pin-mapping.md)），
所以**原板不用改板、不用转接板，引脚 1 对引脚 1 直接焊**。

> 早期的 CH32V307RCT6（LQFP-64）+ LQFP48→LQFP64 转接板方案已作废。

## 4 步流程

1. **焊下原主控**：热风枪 / 烙铁拆下原板上的 STM32F103C8T6（LQFP-48）。
2. **清理焊盘**：吸锡带拖平焊盘，加少量助焊剂清洁，核对丝印 **引脚 1 的圆点 / 缺角方向**。
3. **焊上新主控**：焊上 CH32V303CBT6（同 LQFP-48、同引脚编号），
   **注意引脚 1 方向**，四边对齐后拖焊，最后检查连锡。
4. **烧录验证**：无需转接板、无需改板；原板晶振、电源、充电、外设电路全部不动。
   用 **WCH-Link** 走 PA13(SWDIO) / PA14(SWCLK) 烧录，或走串口 ISP（BOOT0 接高电平）。

## 注意事项

| 项目 | 说明 |
|---|---|
| 方向 | 引脚 1 与丝印圆点对齐，**方向错了上电必坏** |
| 封装 | 必须 LQFP-48（7×7mm），CH32V303**CB**T6；不要买成 LQFP-64 的 V307 型号 |
| 电源 | VDD = 24/36/48 脚接 3.3V，VSS = 23/35/47 脚接 GND，与原板完全一致 |
| 晶振 | 原板 8MHz 晶振电路不动；固件用内部时钟，晶振可保留（也可不焊） |
| 烧录接口 | SWD：PA13=34(SWDIO)、PA14=37(SWCLK)；复位 NRST=7 |
| BOOT0 | 44 脚，正常运行为低；串口 ISP 烧录时接高电平 |
| 舵机供电 | 舵机 5V 单独供电（330µF ×5 滤波），必须与主控共地 |
| 固件 | 链接脚本按 **Flash 128KB / SRAM 32KB** 配置；BSP 可用官方 `ch32v307v-r1` |
| 时钟 | 主频按 **144MHz** 计算定时器预分频（`dog_config.h` 的 `DOG_TIM_CLK_HZ`） |

## 常见问题

- **认不到芯片 / 烧录失败**：检查 3.3V、GND、SWDIO/SWCLK 是否虚焊，NRST 是否被拉低；
  WCH-Link 需选 RISC-V 模式。
- **舵机抖动 / 发热**：主频与定时器时钟不匹配，核对 `DOG_TIM_CLK_HZ` 是否为 144MHz。
- **OLED 不亮**：确认地址 0x78，以及 SCL=PB8 / SDA=PB9。
- **串口无反应**：USART3 为 PB10(TX) / PB11(RX)，与 ASRPRO 交叉连接（TX→RX）。
